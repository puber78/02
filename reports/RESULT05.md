## 1. 问题与判定规则（事前写定）

**问题**：在主预算 b=40 下，数字规则选出的模型，在独立评价池 T_pilot（700 源）上的物理 AUC，
是否显著低于同预算"真实直接规则"选出的模型？

- 数字规则：C_b 上 S_dig（clean/F1_jpeg/F2_scale/F3_blur/F4_color 五个族 AUC 的等权平均）取 argmax；
- 真实直接规则：C_b 上物理 AUC 取 argmax；
- regret = 真实直接所选模型的物理 AUC − 数字规则所选模型的物理 AUC；
- δ = 0.01；主预算 b=40；辅助 b=20、b=80；
- 判读：联合 95% CI 相对 0 与 δ 的位置（三种结论语句，不容许事后改主端点）。

## 2. 数据与权限

| 项 | 值 |
| --- | --- |
| 校准池 | C_pool，**199 源**（200 源中 1 源因隐私替换被排除，见 EXAM02 §3） |
| 评价池 | T_pilot，**700 源**（350 真 / 350 AI） |
| 数字分数 | EXAM03（C_pool：clean + F1–F4）与 EXAM04（T_pilot：clean + F1–F4），共 6 模型 |
| 物理分数 | `manifests/EXAM02/EXAM02_captures_1000.parquet`，源级均值（重复拍摄合并） |
| D_sel | 未参与 EXAM05 |
| 盲法 | **非盲**；T_pilot 物理分数在本分析前已可见（DEC-0010 已披露） |

## 3. 方向口径（DEC-0011）

- 主口径：**方向校正**。校正方向在 C_pool 数字 clean 分数上确定（不读物理）：
  `resnet_ai = −1`、`vit_ai_real = −1`，其余 `+1`。
- 敏感性：**声明方向**（不校正），结果见 §8。
- 全池 S_dig（方向校正后）：swinv2 0.911、siglip 0.880、sdxl 0.847、resnet 0.638、convnext 0.567、vit 0.525。

## 4. 主结果：b = 40

### 4.1 全池参考（b = 199，非主分析）

数字规则与真实直接规则**选中同一个模型：swinv2_deploy**。
即：在完整 C_pool 上，数字排序与物理排序的冠军一致，S_dig 领先第二名 0.031。

### 4.2 外层重放（200 次，无放回抽 40 源）

| 指标 | 值 |
| --- | --- |
| regret 均值 | **+0.0031** |
| regret 中位数 | 0.0000 |
| regret 5% / 95% 分位 | −0.1215 / +0.1215 |
| P(regret > 0) | 0.175 |
| P(regret > δ=0.01) | 0.175 |
| P(数字规则更好) | 0.135 |
| 数字所选模型在 T_pilot 的平均 AUC | 0.8661 |
| 真实直接所选模型的平均 AUC | 0.8692 |
| 选中模型分布（数字） | swinv2 120 / siglip 52 / sdxl 28 |
| 选中模型分布（真实直接） | swinv2 132 / siglip 41 / sdxl 27 |

### 4.3 联合推断（重抽 C_b 与 T_pilot，2000 次）

| 指标 | 值 |
| --- | --- |
| regret 均值 | **−0.0033** |
| 95% CI | **[−0.1224, +0.1193]** |
| P(regret > 0) | 0.114 |
| P(regret > δ) | 0.114 |

**判读：CI 覆盖 0 且横跨 ±0.12，既不能证明"数字选型造成实质损失"，也不能排除。**
按 PREDICTION05 的事前规则，只能写"损失 < δ 或无法区分"这一类结论。

## 5. 预算效应

| 预算 | regret 均值 | 95% 重放 CI | P(regret>0) | 选中 swinv2 比例（数字） |
| --- | ---: | --- | ---: | ---: |
| b=20 | +0.0042 | [−0.1215, +0.1215] | 0.155 | 107/200 |
| **b=40** | **+0.0031** | **[−0.1215, +0.1215]** | **0.175** | **120/200** |
| b=80 | −0.0009 | [−0.0781, +0.0445] | 0.065 | 161/200 |

- 预算从 20 增到 80，CI 半宽从 0.12 收窄到约 0.06，但**在 b=80 仍未达到 ±0.05**。
- 按 PREDICTION05 的否证条件：**该设计在当前 C_pool 规模下无法把"选型损失"钉到 δ 量级**，
  这是设计局限，不得用点估计下结论。

## 6. 选择稳定性与失败模式

- b=40 时数字规则只有 3 个候选会赢：swinv2（60%）、siglip（26%）、sdxl（14%）。
- **灾难性错选**（选到 convnext/resnet/vit）在 b=40、b=80 均为 0 次；b=20 出现 2 次（各 1 次）。
- 条件 regret：当数字规则**选错**（非 swinv2）时，平均 regret = **+0.0305**（b=40）；
  当它选对时 regret 恒为 0。
- 含义：失败不是"选到垃圾模型"，而是"在 swinv2 与 siglip 之间摇摆"——两者物理差约 0.045，
  恰好与 b=40 的估计噪声同量级。

## 8. 敏感性：声明方向（不校正）

方向全部取 +1（resnet 数字 AUC 0.343、vit 0.475）时，结果几乎不变：

| 预算 | regret 均值 | 95% CI | P(regret>0) |
| --- | ---: | --- | ---: |
| b=20 | +0.0015 | [−0.1215, +0.1215] | 0.155 |
| b=40 | +0.0031 | [−0.1215, +0.1215] | 0.175 |
| b=80 | −0.0009 | [−0.0781, +0.0445] | 0.065 |
| 联合 b=40 | −0.0033 | [−0.1223, +0.1182] | 0.114 |

原因：方向校正只影响两个弱模型，而它们从未在任何预算下被选中（除 b=20 的 2 次）。
**方向口径不影响 EXAM05 结论**，但影响"弱模型是否被排除"的叙述。

## 9. 判读（对照 PREDICTION05）

- 事前预测"regret 均值在 0 附近、区间跨 0" → **命中**。
- 事前预测"数字规则可能选错第二三名而非冠军" → **命中**（b=40：60% 选对冠军，40% 在亚军/季军间摇摆）。
- 事前否证条件"b=80 的 CI 仍宽于 ±0.05" → **触发**，记为设计局限 L05-1。
- 结论语句（限定）：
  > 在 b=40、C_pool 199 源的条件下，没有证据表明数字规则选型造成超过 δ=0.01 的物理 AUC 损失；
  > 但 95% CI 宽达 ±0.12，**不能排除**最大约 0.12 的损失。b=80 时 CI 收窄到 [−0.078, +0.045]。

## 10. 局限与对论文的含义

**局限**
- L05-1：C_pool 仅 199 源，b≤80 时选择噪声与模型间真实差距同量级，选型问题**欠功效**。
- L05-2：只有 6 个候选，且其中 3 个（convnext/resnet/vit）物理 AUC≈0.55，实际竞争只在 3 个之间。
- L05-3：T_pilot 与 C_pool 同设备、同会话族，选型损失的"外部"成分未覆盖。
- L05-4：非盲（DEC-0010）。

**对论文的含义（重要）**
- 原先设想的动机——"按数字选型会选错模型、造成实质损失"——**没有得到支持**。
  不能用它作为方法论文的开场白。
- 但换一个更准确的动机仍然成立：**数字排名在冠军层是稳的，代价发生在亚军层**；
  且 b=40 的估计噪声（±0.12）远大于模型间真实差（0.045），说明**"用 40 张校准就想选出最优模型"本身不可靠**。
- 这为方法论文提供了另一个切口：不是"数字会选错"，而是"**少量实拍校准的选择噪声被严重低估**"——
  这正好接上 E3/E4（校准/TTA 能否在低预算下降低选择方差）。
